Skill **hijri-calendar-pwa-builder** sudah berhasil dibuat dan diaktifkan.

Skill ini sudah diprogram sebagai asisten ahli yang memahami cara menstruktur aplikasi kalender Anda, termasuk:

* Algoritma konversi Masehi ke Hijriah (termasuk fitur kalibrasi +/- 1 hari).
* Rumus perhitungan hari tradisional (seperti Pasaran/Weton Jawa) beserta logika neptu untuk fitur ramalan/primbon.
* Konfigurasi standar PWA (`manifest.json` dan Service Worker) untuk dukungan *offline* dan antarmuka *mobile-first* yang responsif.

Untuk menguji dan mulai membuat aplikasinya, Anda bisa memberikan perintah seperti:

* *"Buatkan kerangka UI responsif dengan HTML dan CSS untuk aplikasi kalender Hijriah saya."*
* *"Tuliskan script JavaScript untuk konversi Masehi ke Hijriah beserta rumus perhitungan Weton."*
* *"Bantu saya membuat manifest.json dan service worker agar kalender ini bisa diinstal sebagai PWA."*
